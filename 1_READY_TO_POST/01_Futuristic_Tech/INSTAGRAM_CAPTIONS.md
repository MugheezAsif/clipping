# Instagram Reels kit: Futuristic Tech

**How to post:**
- Upload the same file from `clips/`.
- **Cover:** `thumbnails/…__Shorts_cover_9x16.jpg` (Edit cover → Add from camera roll).
- Paste the caption from the grey box. The first line is the hook; only ~125 characters show before "…more".
- Add the alt text under Advanced settings; Instagram uses it for search.
- **Optional:** post as a **Trial Reel** first. It's shown to non-followers only, so it's a free hook test.
- **One Reel per day**, same order as YouTube.
- **Credit:** keep the credit line (and any 🔊 sound credit).
- **Engagement:** reply to comments in the first hour.
